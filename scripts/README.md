# Проект "Посмотри в окно"

Это веб-приложение, которое позволяет пользователю "выглянуть" в окно в разных городах мира. Проект подгружает видеоролики и отображает их в интерфейсе.

## Технологии
* HTML5
* CSS3 (Grid, Flexbox, кастомные формы)
* JavaScript

## Как запустить
1. Скачайте проект.
2. Откройте файл index.html в браузере.
Ссылка на репозиторий: https://github.com/jane1825/posmotri-v-okno-ad
